# 🚀 Adaptive Task Manager

A modern, responsive productivity web application built using **HTML, CSS, and Vanilla JavaScript**. It helps users efficiently organize, prioritize, and manage daily tasks with a clean user interface and persistent local storage.

## 🌐 Live Demo

👉 **https://saransathis.github.io/adaptive-task-manager/**

---

## ✨ Features

### ✅ Task Management
- Add new tasks
- Delete tasks with confirmation dialog
- Mark tasks as completed
- Undo completed tasks

### 📊 Dashboard
- Total Tasks
- Pending Tasks
- Completed Tasks

### 🎨 User Experience
- Modern responsive UI
- Professional task cards
- Toast notifications
- Keyboard shortcuts
- Human-readable due dates
- Priority badges
- Category badges
- Completed task indicator

### 💾 Storage
- Local Storage support
- Tasks persist after page refresh

---

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| **Enter** | Save Task |
| **Esc** | Close Modal |
